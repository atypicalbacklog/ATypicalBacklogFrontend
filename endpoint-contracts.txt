--------------------------------------------------------------------------------
3.3 Create Retroactive Session (Time Booking After the Fact)
--------------------------------------------------------------------------------
Method: POST
Path: /api/playthroughs/{playthroughUid}/sessions/retroactive
Content-Type: application/json

Path Parameters:
- playthroughUid (string): Unique identifier of the playthrough

Request Body:
{
  "date": "YYYY-MM-DD",   // LocalDate – day for the booking (start at noon)
  "minuteCount": 120      // int, 1-600 (max 10 hours); rejected if > 600
}

Behaviour:
- Time booking is created with startTime = date at 12:00 (noon), endTime = startTime + minuteCount.
- If endTime would fall on the next calendar day, startTime is shifted earlier so both start and end are on the same day (end = end of that day).
- minuteCount > 600 returns 400 Bad Request.

Response: 200 OK
{
  "timeBookingUid": "string",
  "startedAt": "2024-01-01T12:00:00Z",   // ISO-8601 Instant
  "stoppedAt": "2024-01-01T14:00:00Z",   // ISO-8601 Instant
  "durationSeconds": 7200
}

5. QUERY ENDPOINTS – GAME OVERVIEW
================================================================================
Base Path: /api/query/game-overview

--------------------------------------------------------------------------------
5.1 Game Overview Query
--------------------------------------------------------------------------------
Method: POST
Path: /api/query/game-overview
Content-Type: application/json

Request Body:
{
  "searchText": "string" | null,           // optional; LIKE %text% on game/instance/dlc name
  "platformUids": [ "string" ] | null,     // optional; filter by platform UIDs
  "consoleUids": [ "string" ] | null,      // optional; filter by console UIDs
  "inBacklog": true | false | null,        // optional; filter by backlog state
  "hasActivePlaythrough": true | false | null,  // optional
  "completionStateUids": [ "string" ] | null,   // optional; filter by completion
  "playthroughTypeUids": [ "string" ] | null,   // optional; filter by playthrough type UIDs
  "includeDlc": true | false | null,       // optional; when true, include DLC as own records
  "onlyGamesWithDlc": true | false | null, // optional; when true, only games that have DLC
  "sortMode": "NAME_ASC" | "NAME_DESC" | "PLAYTIME_DESC" | "LAST_PLAYED_DESC" | "NEWEST_CREATED" | "RELEASE_DATE"
}

SortMode enum:
- NAME_ASC
- NAME_DESC
- PLAYTIME_DESC
- LAST_PLAYED_DESC
- NEWEST_CREATED      // sort by creation date (instance or game) descending
- RELEASE_DATE        // sort by release date (instance if set, else game) descending

Response: 200 OK
Array of GameOverviewRowDto (each row is either an instance or a DLC):
[
  {
    "isDlc": true | false,                 // true = DLC row, false = instance row

    "gameUid": "string",
    "gameInstanceUid": "string" | null,    // null if no instance exists
    "dlcUid": "string" | null,             // non-null when isDlc is true
    "hasInstance": true | false,

    "gameName": "string",
    "gameReleaseDate": "YYYY-MM-DD" | null,

    "instanceName": "string" | null,
    "instanceReleaseDate": "YYYY-MM-DD" | null,
    "instanceReceivedDate": "YYYY-MM-DD" | null,
    "inPossession": true | false,

    "platformUid": "string" | null,
    "platformName": "string" | null,
    "variantUid": "string" | null,
    "variantName": "string" | null,

    "instanceCoverImageUid": "string" | null,  // game instance cover when available

    "dlcName": "string" | null,            // non-null when isDlc is true
    "dlcReleaseDate": "YYYY-MM-DD" | null,    // non-null when isDlc is true

    "inBacklog": true | false,
    "hasActivePlaythrough": true | false | null,  // null when DLC not linked to playthrough
    "completionStateUid": "string" | null,

    "totalPlaytimeSeconds": 0 | null,      // null when DLC not linked to playthrough
    "coverImageUid": "string" | null,      // game/instance fallback cover

    "hasDlc": true | false                 // instance has at least one DLC
  }
]

Notes:
- DLC rows (isDlc=true) have playthrough/completion data from the DLC's linked playthrough;
  null when DLC is not linked to a playthrough
- Instance rows (isDlc=false) always have playthrough/completion data from instance

- aspect (string, optional): VERTICAL | HORIZONTAL | SQUARE | FREE – used when returning placeholder

Behaviour:
- thumbnail absent → placeholder image
- thumbnail=false and image exists → original image
- thumbnail=true and thumbnail exists → thumbnail
- thumbnail=true and thumbnail absent but original exists → original (fallback)
- otherwise → placeholder

Response: 200 OK
Content-Type: image/jpeg
Body: Binary image data
