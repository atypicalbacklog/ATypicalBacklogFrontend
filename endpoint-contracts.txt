NOTES
================================================================================
- All endpoints return JSON responses (or no body where noted)
- Date formats:
  * LocalDate: YYYY-MM-DD (e.g., "2024-01-15")
  * Instant: ISO-8601 format with timezone (e.g., "2024-01-15T12:00:00Z")
- All UIDs are string values
- Error responses are not explicitly defined in the current implementation
- The API uses Spring Boot's default error handling
